Política de Privacidade

Última atualização: 27 de setembro de 2026

Esta política descreve como o Shorts Bot ("o app") trata informações. O app é uma ferramenta de uso pessoal, executada no computador do próprio desenvolvedor, que publica cortes de vídeo no canal do YouTube do próprio desenvolvedor. O app não é oferecido ao público.

1. Dados da conta Google acessados

O app solicita somente a permissão https://www.googleapis.com/auth/youtube.upload, que permite enviar vídeos ao canal do YouTube da conta que autorizou o acesso. Essa permissão é usada exclusivamente para publicar cortes que foram previamente aprovados manualmente pelo titular da conta.

O app não lê e-mails, contatos, arquivos, histórico, inscrições, comentários nem qualquer outro dado da conta Google ou do canal.

2. Como os dados são armazenados

O token de autorização emitido pelo Google fica armazenado apenas localmente, no computador onde o app é executado. Ele não é enviado a servidores do desenvolvedor, porque o app não possui servidores próprios. Os vídeos processados ficam temporariamente no mesmo computador e são apagados após a publicação ou a rejeição.

3. Compartilhamento

Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou usado para treinar modelos de inteligência artificial. O processamento de vídeo e de áudio (transcrição e seleção de trechos) é feito localmente. As prévias dos cortes são enviadas apenas ao chat privado do próprio desenvolvedor no Telegram, para aprovação.

4. Uso Limitado

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Serviços de API do YouTube

O app usa os Serviços de API do YouTube. Ao usar o app, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

6. Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google. Depois disso, o app não consegue mais publicar vídeos. Os dados locais podem ser apagados excluindo a pasta do app no computador onde ele é executado.

7. Alterações

Esta política pode ser atualizada se o funcionamento do app mudar. A data da última atualização fica no topo desta página.
